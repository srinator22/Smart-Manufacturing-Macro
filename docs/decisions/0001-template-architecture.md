# 0001 - Template architecture

Date: 2026-08-01
Status: accepted

## Context

This template is operated end to end by coding agents across multiple
harnesses (Claude Code, Codex CLI, Cursor, Gemini CLI, and others). Humans
give tasks, answer the start interview, approve specs and lessons, and
authorize irreversible actions; no human writes code. Agent context
windows compact mid-task; an agent grading its own work is the least
reliable signal in the system; resident prose costs context every turn
and gets ignored under pressure. The full build specification is
`docs/BLUEPRINT.md`.

## Decision

- `AGENTS.md` is the single source of truth for every harness. `CLAUDE.md`
  is exactly one line, `@AGENTS.md`, an import for Claude Code. No second
  instruction file exists.
- The kernel section of AGENTS.md is hash-pinned (`.kernel.hash`,
  `scripts/kernel-hash.sh`). No harness can hard-block an agent from
  editing a file, so the design detects drift instead of pretending to
  prevent it: check.sh fails loudly on mismatch, and a legitimate edit is
  a deliberate two-step (edit plus `--update`) visible in the diff.
- `scripts/check.sh` is the single gauntlet; CI runs the exact same
  script, so local and CI cannot diverge.
- Memory has four tiers: resident (AGENTS.md, hard 180-line budget),
  triggered (lessons INDEX and the rules index, opened on match),
  queryable (docs/decisions/, CHANGELOG.md, git log), and task state
  (`.work/TASK.md`, committed so it survives compaction). Learning is
  gated on external signal plus human approval; forgetting is mandatory
  via hard caps and retire-when conditions.
- `CHANGELOG.md` is generated by git-cliff from Conventional Commit
  bodies. Hand-edited changelogs were rejected: generated artifacts are
  never hand-edited (kernel rule 18), and commit bodies make the record
  atomic by construction - the change and its description land in the
  same commit or not at all.
- CLI tools over MCP servers: MCP schemas cost resident context every
  turn; CLIs cost nothing until invoked (see manifest.md).
- Delegation: the main session is the advisor - it decomposes, designs,
  reviews, verifies, and commits. Workers execute bounded mechanical
  tasks and are denied git commit/push. A monitor agent watches every
  push to terminal state.

## Consequences

- Any agent in any harness can operate the repo from AGENTS.md and
  docs/procedures/ alone; `.claude/` is an optional accelerator and the
  repo functions without it.
- Kernel edits are visible, deliberate, and human-approved, at the cost
  of one extra command when a change is legitimate.
- One verification path removes the "passes locally, fails in CI" class
  of drift entirely.
- Resident context stays small and stable; detail loads on trigger or on
  query.
- The changelog is only as good as commit bodies; commit discipline is
  carried by kernel rule 6 and reviewed at ship time.

See `docs/BLUEPRINT.md` for the complete specification this repository
was built from.
