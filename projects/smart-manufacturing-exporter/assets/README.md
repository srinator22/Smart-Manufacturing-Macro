# Smart Export visual assets

These project-owned assets provide the Smart Export ribbon and window identity. They contain no Autodesk artwork or third-party logo.

| Path | Purpose |
| --- | --- |
| `icons/smart-export-16.xaml` | 16-unit vector master for the 16, 20 and 24 px ribbon icons |
| `icons/smart-export-32.xaml` | 32-unit vector master for the 32, 40, 48 and 64 px ribbon icons |
| `ribbon/smart-export-<dark\|light>-<size>.png` | Generated ribbon icons, embedded by the AddIn project and chosen at activation by `WmpRibbon.RibbonIcons` |
| `ribbon/smart-export-light-32.png` | Also the Smart Export window icon (UI project resource) |

The masters are the source. The PNGs in `ribbon/` are generated by `dotnet run --project shared/WmpIconRenderer` and checked against the masters by `scripts/check.sh`; never edit them by hand. The design is an isometric part with a gold export arrow, drawn to the rules in [docs/rules/ribbon-icons.md](../../../docs/rules/ribbon-icons.md).

## Superseded files

`smart-export-logo.png`, `smart-export-16.png` and `smart-export-32.png` are no longer referenced by any project and are waiting to be archived (BACKLOG.md). The logo was generated with OpenAI's built-in image generation tool on 2026-09-14; the 16 and 32 px files were downscaled from it.
