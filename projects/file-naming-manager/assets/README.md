# File Naming Manager visual assets

These project-owned assets provide the File Naming Manager ribbon and window identity. They contain no Autodesk artwork or third-party logo.

| Path | Purpose |
| --- | --- |
| `icons/analyze-naming-16.xaml`, `icons/analyze-naming-32.xaml` | Vector masters for the Analyze Naming command (a tag with a lens) |
| `icons/apply-naming-16.xaml`, `icons/apply-naming-32.xaml` | Vector masters for the Apply Naming command (a tag with a pencil) |
| `ribbon/<icon>-<dark\|light>-<size>.png` | Generated ribbon icons, embedded by the AddIn project and chosen at activation by `WmpRibbon.RibbonIcons` |
| `ribbon/analyze-naming-light-32.png` | Also the File Naming window icon (UI project resource) |

Each command has its own icon. The 16-unit master draws the 16, 20 and 24 px sizes and the 32-unit master the 32, 40, 48 and 64 px sizes. The masters are the source: the PNGs in `ribbon/` are generated by `dotnet run --project shared/WmpIconRenderer` and checked against the masters by `scripts/check.sh`, and are never edited by hand. Authoring rules are in [docs/rules/ribbon-icons.md](../../../docs/rules/ribbon-icons.md).
